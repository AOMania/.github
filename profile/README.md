# AOMania

![AOMania](./logo-lockup.png)

AOMania es un proyecto comunitario de **Argentum Online**: cliente, servidor y herramientas de recursos mantenidos de forma coordinada.

Web del reino: [aomania.net](https://aomania.net)

## Repositorios

- [Cliente](https://github.com/AOMania/Cliente) — cliente VB6 unificado y `AoMania.exe`.
- [Servidor](https://github.com/AOMania/Servidor) — servidor de juego y portal.
- [AOMania-DLLs](https://github.com/AOMania/AOMania-DLLs) — DLLs, `NET_GESE` y `ResourceWorkspace` canónico.

## Recursos

Los paquetes de gráficos e interfaces se mantienen desde `AOMania-DLLs/tools/ResourceWorkspace` y se verifican contra los paquetes del Cliente antes de publicarlos.

## Estado

Los repositorios de código del proyecto son privados. Las incidencias y propuestas se gestionan dentro de GitHub.
